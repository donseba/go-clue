The Go-Clue logo comes from the [Go-WebThings logo generator](https://gowebthings.com/generate)
with `Clue` as the text. The source PNG is available at
`https://gowebthings.com/generate/image?text=Clue`.

`go-clue-logo.png` is the original generated banner. `go-clue-icon.svg` crops its
gopher for the square PNG icons, editor package icons, and favicon.
